The raw simulation data we collected and used for this paper can be found in data/

To generate the data used in this paper, do the following:

1. Run ./run_all_experiments.sh (this may take a couple hours)

2. Once ./run_all_experiments.sh is complete, run summarize-results.py to get numerical results

3. Plotting scripts and paper plots can be found in plots/

4. Note that we used experimentally collected mmWave and Sub6 GHz wireless channel frequency response data to generate these results and we are not at liberty to share that experimental data.  As such, some of the scripts will require some modification if that wireless channel frequency response data is not used.
